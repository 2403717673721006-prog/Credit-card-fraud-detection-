# SECTION 1: PREPROCESSING & EXPLORATORY DATA ANALYSIS (Component C — 5 Marks)

## 1. Dataset Description
- **Source:** Machine Learning Group (MLG) at Université Libre de Bruxelles (ULB), distributed via Kaggle.
- **Total Records:** 284,807 transactions.
- **Dimensions:** 31 columns (30 input features + 1 target `Class`).
- **Target Distribution:**
  - `Class = 0` (Legitimate): 284,315 transactions (99.8273%)
  - `Class = 1` (Fraudulent): 492 transactions (0.1727%)
  - **Imbalance Ratio:** **577 : 1**
- **Temporal Horizon:** Exactly 48 hours (0 to 172,792 seconds).
- **Amount Summary:** Minimum $0.00, Median $22.00, Mean $88.35, Maximum $25,691.16, Standard Deviation $250.12.

## 2. Data Quality & Preprocessing Decisions
1. **Missing Value Audit:** Complete inspection yielded **0 missing values (0 nulls)** across all 284,807 rows and 31 columns.
2. **Duplicate Analysis:** Identified **1,081 duplicate coordinate rows**. In financial transaction logs, duplicate PCA coordinates can legitimately occur when identical card amounts are swiped within equivalent time windows; these were documented and retained to preserve original sampling distribution.
3. **Prevention of Data Leakage (Golden Rule):**
   - The entire dataset was **FIRST partitioned using Stratified Train-Test Splitting** (`test_size=0.20`, `stratify=y`, `random_state=42`).
   - Training Set: 227,845 transactions (227,451 Legitimate, 394 Fraud).
   - Test Set: 56,962 transactions (56,864 Legitimate, 98 Fraud).
   - `RobustScaler` was **FITTED EXCLUSIVELY on `X_train[['Time', 'Amount']]`**, and then applied to transform both `X_train` and `X_test`.
   - Never fit transformations on the test split.
4. **Why RobustScaler for Time and Amount:**
   - Standard z-score scaling (`StandardScaler`) is severely distorted by extreme transaction amounts ($25,691.16 max vs $22 median).
   - `RobustScaler` scales features using the median and Interquartile Range (IQR = Q75 - Q25), preventing outliers from collapsing the core variance.
   - Features `V1` through `V28` were already transformed via Principal Component Analysis (PCA) to zero-mean unit-variance components and were left unmodified.

# SECTION 2: MACHINE LEARNING MODEL DEVELOPMENT (Component D — 5 Marks)

## 1. Algorithms Evaluated & Theoretical Explanations

### 1.1 Logistic Regression (Linear Classifier Baseline)
- **Mathematical Principle:** Models log-odds of fraud as a linear combination of features passed through the standard logistic sigmoid function:
  $$P(y=1|X) = \frac{1}{1 + e^{-(\beta_0 + \sum \beta_i X_i)}}$$
- **Class Imbalance Strategy:** Configured with `class_weight='balanced'`, which assigns penalty weights inversely proportional to class frequencies:
  $$w_j = \frac{N}{2 \times N_j}$$
- **Hyperparameters:** `solver='lbfgs'`, `max_iter=1000`, `random_state=42`.

### 1.2 Decision Tree Classifier (Non-Linear Rule Partitioner)
- **Mathematical Principle:** Recursively splits feature space to maximize Gini impurity reduction:
  $$I_G(p) = 1 - \sum p_i^2$$
- **Class Imbalance Strategy:** `class_weight='balanced'`.
- **Overfitting Controls:** Restricted to `max_depth=7`, `min_samples_split=20`, `min_samples_leaf=10` to prevent deep branch memorization of rare noise samples.

### 1.3 Random Forest Classifier (Champion Model)
- **Mathematical Principle:** Ensemble of 100 decorrelated decision trees built via bootstrap aggregating (bagging) with randomized feature subspace sampling ($\sqrt{p}$ features per split):
  $$\hat{y} = \frac{1}{B} \sum_{b=1}^B T_b(x)$$
- **Class Imbalance Strategy:** `class_weight='balanced'`.
- **Hyperparameters:** `n_estimators=100`, `max_depth=10`, `min_samples_leaf=4`, `n_jobs=-1`, `random_state=42`.

### 1.4 K-Nearest Neighbors Classifier (Instance-Based Metric Learner)
- **Mathematical Principle:** Classifies query points based on majority or inverse-distance weighted consensus of $k$ nearest Euclidean neighbors in standardized feature space:
  $$d(x, x') = \sqrt{\sum (x_i - x'_i)^2}$$
- **Computational Optimization & Imbalance Handling:**
  - Evaluating KNN over 228,000 training points against 56,962 test points requires $13 \times 10^9$ distance computations and causes extreme neighborhood drowning by class 0.
  - KNN was trained on an under-sampled training partition (all 394 training fraud cases + a stratified 1:5 ratio of 1,970 legitimate cases = 2,364 points).
  - Hyperparameters: $k=5$, `weights='distance'`, `n_jobs=-1`.

## 3. Model Selection Decision & Justification
- **Champion Selected:** **Random Forest Classifier**
- **Primary Selection Metric:** **Average Precision (PR-AUC = 0.8444)** and **F1-Score (0.8039)**.
- **Academic Justification:**
  - In extreme class imbalance, high accuracy is meaningless (all models scored >97.5%).
  - While Logistic Regression achieved the highest Recall (91.84% vs 83.67%), its low Precision (6.09%) produced **1,388 false alarms**, which in a commercial bank would overwhelm fraud analysts and block legitimate customer spending.
  - Random Forest reduced false alarms by **98.3% (from 1,388 to just 24)** while maintaining an exceptional **83.67% fraud recall rate**.
